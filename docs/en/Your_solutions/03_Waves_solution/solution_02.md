## 2. String Harmonics

For a string fixed at both ends, the fundamental mode has:

L = λ / 2

So,

λ = 2L

Given:
- String length: L = 64 cm = 0.64 m
- Fundamental frequency: f = 330 Hz

First find the wavelength:

λ = 2(0.64) = 1.28 m

Now use the wave relation:

v = fλ

v = 330 × 1.28 = 422.4 m/s

### Final Answer:
The speed of the wave on the string is:

**v = 422.4 m/s**
