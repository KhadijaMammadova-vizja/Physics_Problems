## 3. Superposition Principle

Given two waves:
- y₁(x,t) = A sin(kx − ωt)
- y₂(x,t) = A sin(kx + ωt)

### Step 1: Use trigonometric identity

sin(α − β) + sin(α + β) = 2 sin(α) cos(β)

Let:
- α = kx
- β = ωt

Then:

y(x,t) = y₁ + y₂  
= A sin(kx − ωt) + A sin(kx + ωt)  
= 2A sin(kx) cos(ωt)

### Resulting Standing Wave:

y(x,t) = 2A sin(kx) cos(ωt)

### Step 2: Find nodes

Nodes occur where displacement is always zero:

sin(kx) = 0

kx = nπ  ⇒  x = nπ / k

Since k = 2π / λ:

x = n(λ / 2),  where n = 0, 1, 2, 3, ...

### Final Answer:
- Standing wave:  
  **y(x,t) = 2A sin(kx) cos(ωt)**

- Node positions:  
  **x = n(λ / 2),  n = 0, 1, 2, ...**
