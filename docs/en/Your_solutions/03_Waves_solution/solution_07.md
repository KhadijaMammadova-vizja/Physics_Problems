## 7. Standing Wave Modes

For a string fixed at both ends, the length of the string is related to the wavelength by:

L = n(λ / 2)

where:
- L is the string length
- n is the number of antinodes
- λ is the wavelength

Given:
- L = 80 cm = 0.80 m
- Number of antinodes = 4

So,

0.80 = 4(λ / 2)

0.80 = 2λ

λ = 0.40 m

### Final Answer:
The wavelength of the standing wave is **0.40 m**.
