## 8. Waves

We are given the wave equation:

∂²y/∂x² = (1/v²) ∂²y/∂t²

A function represents a traveling wave if it satisfies this equation and is of the form:
- f(x − vt)  (right-moving), or
- f(x + vt)  (left-moving)

---

### a) y(x,t) = A cos(kx² − ωt)

This is **not** a valid wave:
- The argument contains **kx²**, not kx
- It is not of the form (x ± vt)

❌ Not a traveling wave

---

### b) y(x,t) = A(x − vt)²

This **is** a traveling wave:
- It depends only on (x − vt)

✔ Traveling wave (right-moving)

---

### c) y(x,t) = A log(x + vt)

This **is** a traveling wave:
- It depends only on (x + vt)

✔ Traveling wave (left-moving)

---

### Final Answer:
- (a) ❌ Not a traveling wave  
- (b) ✔ Traveling wave  
- (c) ✔ Traveling wave
