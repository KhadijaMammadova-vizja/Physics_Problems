Problem 8 – Definite Integrals

Calculate the area under the curve of the function

f(x) = sin(x)

from x = 0 to x = π.

Solution:
Using an integral:

∫ sin(x) dx

The integral of sin(x) = −cos(x)

Calculate between 0 and π.

−cos(π) − (−cos(0))

it is known:
cos(π) = −1
cos(0) = 1

So:

−(−1) − (−1)

1 + 1 = 2
Answer is 2.
